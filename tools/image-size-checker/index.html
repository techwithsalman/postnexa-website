Frequently Asked Questions

How do I check an image's pixel dimensions and file size online?

Simply drag and drop your image file into the dropzone above or click "Choose Local File". The browser immediately reads the file's naturalWidth and naturalHeight metadata alongside byte size, showing you exact dimensions in milliseconds without uploading to any server.

What is the best website image size to pass Core Web Vitals?

For full-width desktop hero banners, target 1920×1080 pixels under 180 KB in WebP or AVIF format. For blog editorial images, 1200×675 pixels under 90 KB offers the ideal balance of crisp visual clarity and sub-second Core Web Vitals performance.

How do image dimensions differ from file size?

Image dimensions represent pixel width and height (e.g. 1920×1080 pixels). File size represents the byte weight of the file on disk (e.g. 150 KB or 2.5 MB). Resizing modifies pixel dimensions; compressing reduces byte size by optimizing color data without altering pixel resolution.

How can I find image dimensions on a mobile phone or Mac without software?

Open PostNexa's online image size finder in Safari, Chrome, or any mobile browser and select your photo. The tool inspects pixel resolution and aspect ratios locally without requiring Photoshop or command-line tools.

Why do Instagram Reels and TikTok crop headers and captions?

Both platforms place persistent interface icons (usernames, audio discs, like/comment buttons) over the bottom 20% and top 15% of the screen. Keeping text inside safe zones guarantees readability.

What image formats can I inspect?

The checker supports JPG, PNG, WebP, SVG, and GIF formats up to 50MB with instant local preview.
