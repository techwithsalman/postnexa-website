Secure OAuth Architecture

How Official API Publishing Works in PostNexa

PostNexa connects directly to official platform endpoints to ensure your accounts remain secure, authorized, and compliant with developer policies.

1

Scoped OAuth 2.0 Handshake

You authorize PostNexa directly through official Meta, Google, or ByteDance login dialogs. PostNexa never sees, handles, or stores your social account passwords. Access is granted via revocable, encrypted access tokens strictly scoped to page and channel publishing.

2

Pre-Flight Media Validation

Before queuing, PostNexa validates file dimensions, codecs, and container sizes client-side: JPG, PNG, and WebP for image posts; MP4 and MOV (up to 1080p, 9:16 vertical) for Reels and TikTok. This prevents unexpected API rejection errors at publish time.

3

Direct API Container Dispatch

At your scheduled publishing time, PostNexa's automated scheduler creates media containers and initiates direct publish requests to platform API servers. Content posts automatically to your profile without requiring manual mobile push confirmations.
